# Retrospectives

What went well, what did not, and what changes as a result.

## Naming

`sprint-NN-retro.md` — matching the sprint number in
[`../sprint-planning/`](../sprint-planning/).

## Suggested outline

- **Sprint number and dates**
- **What went well**
- **What did not go well**
- **Actions** — each with a named owner and a target sprint

Actions are the point of the document. An action without an owner will not
happen; carry unfinished actions forward into the next retro explicitly rather
than letting them lapse.
