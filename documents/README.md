# Documents

Everything that is not source code. Organised by *purpose*, so a document's
location tells you what it is for.

| Folder | Contents |
| --- | --- |
| [`agile/`](agile/) | Sprint planning, backlog, retrospectives |
| [`brand-guidelines/`](brand-guidelines/) | Logo, colour, typography, tone of voice |
| [`product/`](product/) | PRDs, requirements, roadmap, personas |
| [`design/`](design/) | Wireframes, mockups, UX flows, design system |
| [`research/`](research/) | Market and user research, competitor analysis |
| [`meeting-notes/`](meeting-notes/) | Dated notes and the decisions from them |

## Conventions

- **Markdown by default.** Text-based documents are `.md` so they review
  cleanly in a diff. Reach for Word, PowerPoint, or Excel only when the format
  is the point (a client-facing deck, a financial model).
- **Lowercase, hyphenated filenames** — `sprint-04-goals.md`, not
  `Sprint 04 Goals.md`.
- **Date-prefix anything time-bound** as `YYYY-MM-DD-` so it sorts
  chronologically: `2026-07-27-kickoff.md`.
- **Keep assets next to the document that references them.** An image used by
  one document belongs in that document's folder, not a shared dumping ground.
- **One topic per file.** Prefer several short documents over one long one.
