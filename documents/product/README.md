# Product

What we are building, for whom, and why. The intent behind the work — the
process of delivering it lives in [`../agile/`](../agile/).

## What belongs here

| Document | Purpose |
| --- | --- |
| `vision.md` | The problem, the audience, and what success looks like |
| `roadmap.md` | Themes and rough sequencing, not a dated commitment |
| `prd-<slug>.md` | Product requirements for a specific capability |
| `personas.md` | Who the users are, their goals and constraints |
| `metrics.md` | How we know it is working |

## PRD outline

- **Problem** — what is broken today, and the evidence for it
- **Users affected** — link to `personas.md`
- **Goals and non-goals** — non-goals matter as much as goals
- **Requirements** — numbered, so stories can reference them
- **Success metrics** — measurable, with a target
- **Open questions** — resolved before stories are written

Requirements here should be traceable into user stories in
[`../agile/backlog/`](../agile/backlog/).
